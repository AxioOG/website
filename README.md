# Custom Images Guide

## How to Add Your Custom Images

Place your image files in this `images/` folder with these specific names:

### Required Images:

1. **logo.png** - Your website logo (32x32px recommended)
   - Will appear next to "Medusa Bypass" in the navbar
   - Should be square format, will be displayed as circular

2. **hero-bg.jpg** - Hero section background image
   - Large image (1920x1080px recommended)
   - Will be displayed with low opacity behind the hero text
   - Gaming-themed background works best

3. **news1.jpg** - First news card image
   - 800x400px recommended
   - Gaming software or cheat-related image

4. **news2.jpg** - Second news card image
   - 800x400px recommended
   - Anti-cheat or security-related image

5. **news3.jpg** - Third news card image
   - 800x400px recommended
   - Security or update-related image

### Supported Formats:
- JPG/JPEG
- PNG
- WebP
- GIF

### Tips:
- Use high-quality images for better appearance
- Optimize images for web (compress them to reduce file size)
- Dark-themed images work better with the website's design
- If an image fails to load, the website will gracefully hide it

### Example File Structure:
```
web/
├── images/
│   ├── logo.png
│   ├── hero-bg.jpg
│   ├── news1.jpg
│   ├── news2.jpg
│   └── news3.jpg
└── index.html
```

Simply drag and drop your images into this folder and rename them accordingly!
